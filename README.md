# Personal Portfolio

Interactive personal portfolio website featuring custom pixel wave animations and a retro modal UI, built with React, TypeScript, and Vite.

## Links
- **Live Site:** https://jamieyang.netlify.app/
- **GitHub Repository:** https://github.com/jamiejy927/personal-portfolio

## About
I wanted to step away from standard websites and challenge myself to replicate a site I was interested in, learning new interactive techniques along the way. It offers an engaging portfolio experience with interactive pixel wave animations and a retro modal interface to explore my work. (Though it's still a work in progress, I plan to refine and update it over time.)
